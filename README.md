# Spam Email Detection

Problem Statement: In digital communication, the influx of unsolicited and malicious spam emails poses a major security and productivity risk. Manually filtering through incoming messages is inefficient, and traditional rule-based filters often fail to catch sophisticated spam techniques.

Solution: This project implements an end-to-end Machine Learning pipeline to automatically detect and classify spam emails and messages using text preprocessing, TF-IDF feature extraction, and a Naive Bayes classifier.

## Tech Stack
- Data Science: NumPy, Pandas, Matplotlib, Seaborn, Scikit-Learn
- Machine Learning: Multinomial Naive Bayes.

## Setup Installation
